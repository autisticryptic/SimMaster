# IMS 注册模式与 VoWiFi 资费保护

## 标准结论：保留多注册，但不能强行启用

已核对 ETSI 官方发布的 **3GPP TS 24.229 V18.11.0（2026-08，Release 18）**：

- [官方 PDF](https://www.etsi.org/deliver/etsi_ts/124200_124299/124229/18.11.00_60/ts_124229v181100p.pdf)
- §5.1.1.2.1，处理 REGISTER 的 **200 OK 响应的 f 项**，印刷页 106 / PDF 第 107 页。
- [RFC 5626 §4.2.1](https://www.rfc-editor.org/rfc/rfc5626.html#section-4.2.1)、
  [§4.2.2](https://www.rfc-editor.org/rfc/rfc5626.html#section-4.2.2)、
  [§4.4](https://www.rfc-editor.org/rfc/rfc5626.html#section-4.4)、
  [§6](https://www.rfc-editor.org/rfc/rfc5626.html#section-6)。

中文说明：

1. 标准允许同一私有用户身份拥有多个 IMS 注册流，可用于本项目的 WLAN / 蜂窝接入。
2. 客户端先提供 `Supported: outbound`、稳定的 `+sip.instance` 和各流独立的 `reg-id`；
   服务端成功响应中的 `Require: outbound` 才是按该机制处理注册的确认。
   “客户端自己加了字段”或“两个开关都开启”不代表协商成功。
3. 该 3GPP 条款明确要求：成功响应没有确认 outbound 时，不继续为同一私有身份追加 IMS 流。
   规范同时说明，此时新 Contact 可能替换旧 Contact；这与原故障相符，但不是完整的实机根因证明。
4. 还须满足 P-CSCF/首跳支持、绑定匹配及流维护条件。续期使用原注册流及原标识，
   不能通过重建安全关联后重新注册来伪装正常续期。
5. 判断范围是当前接入/协商，不建立运营商永久黑名单；超时也不等于明确不支持。

因此不删除多流实现，也不绕过协商门禁。

默认请求是先声明 `Supported: outbound`，不是在第一条请求中强制网络必须支持；
追加第二流时才要求该机制，避免无声覆盖原绑定。成功响应未确认，或明确拒绝多流时，
退回单注册兼容路径。有效的原绑定继续续期，不为试探能力反复重建安全关联。

## 注册设置

在每条线路的 IMS 页面提供中文设置，复用既有 `/ims/access-preference` 和
`ims_access_preference`，不再增加一套相互冲突的开关：

| 界面选择 | 兼容存储值 | 行为 |
| --- | --- | --- |
| 自动双注册（默认） | `concurrent` | 默认声明 outbound 能力；确认支持且流有效时并行，否则走单注册回退 |
| 仅单注册 | `wlan_preferred` | 不追加第二条注册，优先 VoWiFi |

旧 `cellular_preferred` 配置继续可读取，不在打开界面时静默改写。
单注册选择已启用且可用的 VoWiFi → 蜂窝 IMS；两者不可用时，允许的短信/电话业务才考虑 CS。
**CS 不是第三个 IMS 注册，SIP Trunk 也没有可假装存在的 CS 音频后端。**
已有通话保护、启用意图、每路原通道续期均保留。

## 注册可用性与资费限制是两件事

双注册可以保留蜂窝接入用于接收短信，但不得绕过资费保护：

- 常规呼出和短信发送优先 VoWiFi，再考虑允许的备用路径。
- 短信页“仅通过 VoWiFi 发送”是硬限制；API、自动化和 Trunk 发送都要遵守。
  VoWiFi 失败就返回失败，不退到蜂窝 IMS / CS。
- Trunk 的 VoWiFi-only 保持其原有呼叫和短信发送限制；所有网关呼出、未接通前的
  自动回退及入向接听都必须经过门禁。本地 API / 自动化也不能从同一网关失败后
  绕到原生 CS 呼出或接听；挂断已有通话仍可执行。
- 收短信不受上述发送限制影响；VoWiFi / 蜂窝收到的短信均可入库和转发，保留跨通道去重。
- 本地不能命令运营商把蜂窝来电改送 VoWiFi。启用严格限制时应在接通前拒绝被禁止的
  蜂窝来电，尤其不能让“立即接通运营商侧”模式先发送 200 再过滤。
- 每次尚未执行的回退需重新检查限制，不能继续使用设置变更前缓存的候选列表。
  已发送的短信无法撤回，已建立的通话不会因修改注册模式被迁移或假装免费。

VoWiFi 并不由软件保证按本地资费结算，具体资费仍以运营商规则为准。

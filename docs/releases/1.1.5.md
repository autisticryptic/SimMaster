# SimAdmin 1.1.5

1.1.5 是「统一设备接口、ModemManager 变为可选后端」的版本。
**代码与 CI 状态不等于实机验收**，下文逐项区分。

## 主要内容

- 原生后端（QMI / MBIM / AT）：设备只读发现、AT/URC 事件、短信持久化收件箱与送达报告、
  SIM 通道账本、显式资源恢复 CLI、Quectel / DJI 专项维护入口。
- ModemManager 仍是**默认**后端；native 需显式设置 `mode: native` 与
  `allow_unvalidated_native: true`，不会自动切换。
- IMS 命名迁移（`volte_*` → `cellular_ims_*`）及数据库旧名迁移。
- 纯 Rust DNS（hickory-resolver + system-config）。
- Telegram 通知支持自定义反代地址。
- 只读 IMS 采证脚本 `scripts/ims-readonly-evidence.sh`。

详见 [当前接手说明](../HANDOFF.md) 与 [native 后端状态](../NATIVE_BACKEND_STATUS.md)。

## 版本号说明

源码此前仍标为 `1.1.4-beta3`，与已实现范围不符，本版统一为 `1.1.5`。
GitHub 上曾出现的 `v1.1.8` / `v1.1.7` 来自 2026-09-06 误提交的 VERSION 与旧的
「push 即自动发布」流程，二进制早于本开发线，**不是比 1.1.5 更新的版本**。

构建方面：`VERSION`、`Cargo.toml`、`Cargo.lock`、`package.json` 统一由
`.github/scripts/sync_release_version.py` 写入；测试与打包使用同一版本，
打包使用 `cargo build --locked`，清单不一致会直接失败。

## 尚未验收

- native 后端端到端实机（短信、通话、掉线恢复）。
- 同机 MM / native 混合 owner。
- 未知孤儿资源自动恢复（仅支持显式、需确认的恢复）。
- SIM-06（中国电信）IMS 注册失败，待现场证据；见 [IMS 诊断](../IMS_DIAGNOSTICS.md)。

已通过的 SIM-04 自然续期、SIM-05 手测均走 MM 路径，不能作为 native 验收证据。

## 安装

按 [手动安装指南](../INSTALL.md) 部署，先校验 `SHA256SUMS.txt` 以及包内
`meta.json` 的版本、commit 与架构。旧一键安装 / OTA 流程仍在重构中。
升级保持原配置、数据库与后端选择，不会自动切换 native 或重启设备。

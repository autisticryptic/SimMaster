# 1.1.4-beta3

> 预发布验证版本，非 latest。请明确选择此版本的发布包，不要把 stable/latest 入口当成 beta3。

## 蜂窝 IMS 修复

- 兼容部分 QCM410 固件的紧凑 IPv4v6 `CGCONTRDP` 输出。只有同一 CID 的
  `CGPADDR` 确认两个本地地址后才采用该布局，避免把本地 IPv6 误当作网关、
  漏掉 IPv6 P-CSCF；原标准单地址／分行格式保持兼容。
- DATA6 只向上层提供实际启动的 WDS 地址族。对应地址缺失时交回地址族计划兜底，
  不再用未启动地址族进入长时间的 SIP 变体重试。
- 标准派生 LTE 配置依照 TS 24.229 §5.1.1.2.2，在第一条 IMS-AKA REGISTER 中
  携带私有身份以及空 nonce/response，再正常应答运营商挑战。
  不扩大认证失败后的 403 重试范围，不把重新注册当成 refresh。
- 原生端点未就绪时等待设备初始化，不消耗运营商配置槽，不自动重启基带，
  不回退到宿主网络空间；保留真实前置错误及等待状态。

## 保持的策略

- 默认公告 SIP Outbound 能力，只有网络确认且各 flow/绑定有效时才允许并发；
  否则保持 VoWiFi → 蜂窝 IMS → 允许的 CS 业务回退顺序。
- 短信仅 VoWiFi 发送、Trunk 仅 VoWiFi 通话的成本限制不被注册或业务回退绕过。
- 保留 `cellular_ims` 命名重构、兼容接口以及 Hickory + system-config 的纯 Rust DNS 路径。

## 实机验证范围

- 修复候选 `65b8a0e` 在新的 QCM410/SIM 环境完成正常挑战应答与初始注册。
- 等待正常 3000 秒调度后，同一 UDP 会话自然续期成功，refresh_count 由 0 增至 1，
  会话起始时间、重连计数和主服务进程不变，续得 3600 秒租期。
  没有缩短计时、重启或重建安全关联制造成功。
- 分别激活 ios-ipcc、iPhone 26.6.1、Pixel 和 Xiaomi 四个 catalog 复测，
  均通过标准派生兜底完成初始注册。该 SIM 在这些库中没有可直接采用的 ready LTE 配置；
  不能把这些结果解释为四库各自的运营商专属参数都已通过。
- 其他换库复测只计独立初始注册，不重复计为原通道自然续期。
- 后端编译／回归、前端检查及 arm64、amd64 构建由 GitHub Actions 执行；
  开发分支候选仅生成 artifact，正式版本由主分支发布门禁统一发布。

## 限制

本次网络未确认 Outbound 多注册，协商结果为 UDP，且没有返回 Service-Route。
因此不声称此环境的 IPsec、跨接入双注册、真实通话／短信或资费已实测通过。
库记录为 unknown 不等于运营商不支持 IMS，不篡改 ready 状态，也不冒用其他 MVNO 配置。
后续仍需不同 SIM／运营商环境的持续验证。

# 1.1.4-beta2：蜂窝 IMS 命名与纯 Rust DNS

状态：**预发布验证候选；代码回归已通过，双架构发布构建和本版本实机验收仍需单独记录。**

## 变更

- 蜂窝 IMS 实现模块改为 `cellular_ims`，相应类型、运行时成员、函数、前端组件及代码变量使用准确名称。
- 蜂窝和 WLAN 共用的 profile 类型使用 `ImsProfile*`；真实 VoLTE 标准/运营商字段不做全局字符串替换。
- 新增 `/api/cellular-ims/lines...` 和线路级 `cellular-ims/call/status`；旧 `/volte/...` 端点仍兼容。
- 保留既有 JSON、数据库键、`volte` / `volte_ims` 传输标识及错误码作为兼容编码；新增 `cellular_ims_*` 等读取别名，拒绝重复别名。不会强制改写历史短信、自动化或用户配置。
- 普通系统解析改用 `hickory-resolver 0.25.2`，启用 `tokio`、`system-config`；不再调用 libc `lookup_host`。HTTP 和 SOCKS5 代理端点也使用纯 Rust 解析入口。
- 数字地址不发 DNS；hosts 优先于系统 resolver 配置；每次解析拥有独立有界 resolver，不共享跨 runtime/namespace 的缓存和 socket。
- 专用运营商 DNS、P-CSCF、NAPTR、SOCKS5 UDP DNS 维持既有 Rust 传输和选路策略，不借重构改变出口。
- 补全 SIM DNS 覆盖校验，拒绝非法服务器地址和目标端口 0。
- 修正精简 YAML 补默认子树时的节点插入问题；保留原注释和未修改文本，写入前仍重新解析验证。新增复杂子树使用合法 flow YAML，首次生成配置仍是带注释的块式 YAML。
